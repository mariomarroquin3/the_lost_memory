# The Lost Memory

Escape room narrativo de ciencia ficción construido con TypeScript, Canvas y HTML/CSS.

## Ejecutar localmente

```powershell
npm install
npm run dev
```

Validar el build de producción:

```powershell
npm run build
```

El juego usa WASD o flechas para moverse y `E` para interactuar. `Tab` abre el mapa; la PC de control muestra el estado global.
